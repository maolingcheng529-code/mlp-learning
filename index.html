TensorFlow 版本

python -m pip install tensorflow
python train_tensorflow.py

以上是 Windows 命令。macOS / Linux 激活命令为 source .venv/bin/activate。建议使用 Python 3.11，CPU 即可运行，无需安装两个框架。脚本会输出最终预测，并保存包含 0–300 轮参数、损失和概率的 JSON 文件。

自动求梯度本身不会更新参数：PyTorch 的 backward() 与 step()，对应 TensorFlow 的 tape.gradient() 与 apply_gradients()。隐藏层非线性让网络能够表达 XOR。
